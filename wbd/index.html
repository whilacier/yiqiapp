矩形、圆形、箭头、直线，按住 Shift 还能画出正方形与正圆。画卦象、标方位、连关系，规范又高效。

P / R / O / A / L

临时笔迹，自动淡出

按 F 切换临时笔迹，写下的内容会在设定时间后自动淡出，适合课堂上的临时强调、随写随消。

贴图自由，缩放旋转

Ctrl+I 插入图片，或直接拖拽、粘贴。罗盘、卦图、照片均可轻松贴入，支持拖动、按比例缩放、自由旋转。

Ctrl+Z / Ctrl+Y
📄

Ctrl+N 新建下一页，PageUp/PageDown 自由翻页。一节课多页内容，随时切换，逻辑清晰不混乱。

多页管理

Ctrl+T 一键切换透明/不透明背景。透明模式下，白板可悬浮于其他软件之上，边看资料边画重点。

Killer Feature

🖥️ 桌面标注模式 · 核心亮点

全屏透明覆盖层，直接在桌面或任意程序之上书写标注

🎯 一键进入标注 · 再按即隐

默认 Ctrl+Alt+D 进入全屏透明标注模式， 白板全屏显示、背景透明、窗口置顶，直接在桌面或任意程序之上书写标注。 再按一次同一快捷键，或按 Esc，即隐藏到托盘——不弹保存框，不打断思路。

1

呼出白板

Ctrl+Alt+W 显示/隐藏白板

2

桌面标注

Ctrl+Alt+D 全屏透明标注

3

鼠标穿透

Ctrl+Alt+X 可点击桌面，笔迹保留

4

一键隐藏

Esc 隐藏到托盘，干净利落

🔧 系统托盘与全局快捷键

托盘图标单击/双击 → 显示/隐藏白板；右键 → 打开白板 / 桌面标注 / 退出
关闭按钮默认最小化到托盘（可在"参数配置"里关闭）
呼出快捷键默认 Ctrl+Alt+W：按一次显示白板；再按一次直接隐藏到托盘
桌面标注默认 Ctrl+Alt+D：进入全屏透明标注模式；再按一次隐藏到托盘
穿透切换默认 Ctrl+Alt+X：仅在标注模式下有效，切换鼠标穿透
Esc标注模式下直接隐藏到托盘（不弹保存框、不还原普通窗口）
