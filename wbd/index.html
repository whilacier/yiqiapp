在易学授课、风水勘测、命理推演的过程中，随手画个卦象、标个方位、圈个重点—— 无镜道易学专用手写板 正是为易学从业者与爱好者量身打造的 Windows 桌面手写白板软件。 基于 Qt 6 + C++ 原生开发，性能流畅，支持数位板笔压感应， 内置思维导图连接线、页面模板、图标库、屏幕截图 / 贴图 / OCR 等效率工具， 配合系统托盘与全局快捷键，让每一次讲解都行云流水。

Core Features

核心功能

专为易学场景深度打磨，每一项功能都直击痛点

✍️

真实笔压，书写如纸

完美支持数位板笔压感应，线条粗细、透明度随压力自然变化。轻描淡写是细线，重笔强调则粗犷有力。抬笔时笔锋自然收细，还原真实书写质感。

presets.json 可调
🎨

十组预设，一键切换

数字键 0-9 快速切换十组预设笔色、粗细与线型。黑色细笔标注、红色粗笔强调、虚线辅助线，指尖一按即刻切换。选中笔迹时按数字键可直接改色。

0-9 快捷键
📐

形状工具，规范图示

矩形、圆形、箭头、直线，按住 Shift 还能画出正方形与正圆。画卦象、标方位、连关系，规范又高效。

P / R / O / A / L
NEW
🔗

思维导图连接线

按 C 切换到连接线工具，可绘制两点之间的平滑 S 形贝塞尔曲线。起点、终点自动吸附已有连接线的端点，并显示绿色提示，按住 Shift 可临时禁用吸附，画导图、串逻辑一秒完成。

C 键
NEW
📋

六种页面模板

白纸、横格纸、方格纸、田字格、点阵纸、五线谱——按 Ctrl+Shift+T 呼出模板对话框，可选择仅当前页 / 当前页及后续 / 全部页面。线条颜色、粗细、间距均可在参数配置里调整，.wbd 文件按页记住各自模板。

Ctrl+Shift+T
NEW
⭐

内置图标库

按 Ctrl+Shift+I 呼出 Font Awesome 7 图标选择器，内置重要度、状态、方向、工具、文档、人物、图表、数字九大分类。支持自定义颜色、大小，双击插入即可连续添加，矢量渲染缩放不失真。

Ctrl+Shift+I
✨

临时笔迹，自动淡出

按 F 切换临时笔迹，写下的内容会在设定时间后自动淡出，适合课堂上的临时强调、随写随消。

F 键切换
🖼️

贴图自由，缩放旋转

Ctrl+I 插入图片，或直接拖拽、粘贴。罗盘、卦图、照片均可轻松贴入，支持拖动、按比例缩放、自由旋转。透明背景 PNG 会保留透明。

拖拽 / Ctrl+V
🧹

笔迹编辑，随心所欲

Shift+划过 擦除，Ctrl+划过 单个切换选中，Ctrl+划圈 圈选全部。选中后可整体拖动、复制、剪切、删除。撤销上限可在配置中调整，默认 8 步，最高 200 步。

Ctrl+Z / Ctrl+Y
📄

多页白板，课程连贯

Ctrl+N 新建下一页，PageUp/PageDown 平滑翻页动画。Ctrl+G 输入页码跳转，Ctrl+Home/End 直达首尾页，Ctrl+Shift+←/→ 快跳 10 页。

多页管理
NEW
🪟

多窗口，互不干扰

双击 .wbd 文件或启动第二个实例时，会在主实例里新开一个完全独立的窗口，各自拥有独立的页面、撤销栈与选择状态。一份白板给讲师、一份给学员，同步对照不打架。

多窗口独立
🌫️

透明背景，叠加讲解

Ctrl+T 一键切换透明/不透明背景。透明模式下，白板可悬浮于其他软件之上，边看资料边画重点。

Ctrl+T
💾

保存导出，分享便捷

保存为 .wbd 格式，完整保留所有页面、笔迹与贴图（zip + JSON + WebP/PNG 结构，与 PySide6 版完全兼容）。导出 PNG，或 300 DPI 打印级 PDF，Ctrl+M 批量合并为 PDF。

.wbd / PNG / PDF
📕

导入 PDF，直接标注

Ctrl+P 导入 PDF，逐页渲染为白板背景（后台多线程渲染，UI 不卡顿），可直接在其上书写批注，再保存为 .wbd，源 PDF 删除也不影响。带书签的 PDF 可用 Ctrl+L 呼出目录面板，点击条目即跳转。

Ctrl+P / Ctrl+L
🗂️

图片库侧边栏

Ctrl+H 开关左侧图片库，把罗盘、卦图等常用素材拖到画布即可插入贴图，双击插入到画布中心。支持 PNG / JPG / BMP / GIF / WebP / SVG，缩略图带磁盘缓存。宽度可调，一键重新扫描文件夹。

Ctrl+H · 拖拽插入
✂️

选中即编辑，多选整组变换

选中笔迹或贴图后，拖动内部可整体移动；拖拽四角可缩放（右下角等比、其余自由）；拖顶部圆点旋转（Shift 每 15° 吸附）。多选时支持整组缩放 / 旋转。

8 个锚点 + 旋转
📋

智能粘贴

按 Ctrl+V 时自动识别剪贴板内容：白板内部对象 → 原位粘贴并选中；位图 → 贴为图片；图片文件 / SVG / PDF 首页 → 转为贴图；HTML 富文本 / Markdown / 颜色值 / 文件列表 → 自动渲染为精美图片贴入。

Ctrl+V

🔧 系统托盘与全局快捷键

托盘图标单击/双击 → 显示/隐藏白板；右键 → 打开白板 / 桌面标注 / 截图 / 贴图 / OCR / 退出
关闭按钮默认最小化到托盘（可在"参数配置"里关闭）
呼出快捷键默认 Ctrl+Alt+W：按一次显示白板；再按一次直接隐藏到托盘
桌面标注默认 Ctrl+Alt+D：进入全屏透明标注模式；再按一次隐藏到托盘
穿透切换默认 Ctrl+Alt+X：仅在标注模式下有效，切换鼠标穿透
Esc标注模式下直接隐藏到托盘（不弹保存框、不还原普通窗口）
Efficiency Suite

✂️ 屏幕效率套件

截图 · 贴图 · OCR，全局快捷键一点即用，让屏幕上的内容随手可标注、可提取

📷

屏幕截图

全屏覆盖层带放大镜、十字准线与实时颜色值显示。移动鼠标 → 两次点击完成选区；按住 Ctrl 一键切换为窗口截图模式，光标所在窗口或子控件会被高亮，单击即可精确截取。截图完成后自动弹出"屏幕贴图"窗口，可直接在截图上标注。

Alt+Q
📌

屏幕贴图

把剪贴板里的图片、图片文件，甚至一段文字，贴到屏幕任意位置。贴图窗口独立置顶，非标注模式下拖动即可移动，Ctrl+滚轮 以光标为锚点缩放，按 空格 切换标注模式后可直接在贴图上书写，按 Esc 把当前贴图（含标注）复制到剪贴板并关闭。

Alt+W
🔍

截屏 OCR 文字识别

全屏框选任意屏幕区域，调用 Windows 10 / 11 系统内置 OCR 引擎（本地识别，无需联网）自动提取文字，结果弹窗显示，自动复制到剪贴板，也可一键转为贴图插入白板。系统自动匹配中英日韩等已安装语言包。

Alt+R

💡 全部快捷键均可在「参数配置 → 托盘 / 快捷键」里自由修改，若被其他程序占用会提示注册失败，换一个组合即可。
